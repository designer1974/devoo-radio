# Devoo Radio 🌍

Radio di tutto il mondo su una mappa, per Android (Flutter + Kotlin).

- **Mappa del mondo**: ogni puntino verde è una città con le sue radio. Tocca e ascolta.
- **Sorprendimi**: una radio a caso da qualsiasi paese.
- **Cerca** per nome, genere o paese (decine di migliaia di stazioni).
- **Preferiti** e **ascoltate di recente**.
- Suona **in background** con i controlli nella notifica e nelle cuffie.
- Titolo del brano in onda, **spegnimento automatico**.
- Le radio si salvano sul telefono: l'app si apre subito e si aggiorna da sola ogni settimana.

Dati delle stazioni: [radio-browser.info](https://www.radio-browser.info) · Mappa: © OpenStreetMap, © CARTO.

## Scaricare l'APK

Ogni modifica su `main` compila l'app in automatico: l'ultima versione è nella pagina **Releases**.
- `DevooRadio.apk` → telefoni moderni (64 bit)
- `DevooRadio-telefoni-vecchi.apk` → telefoni vecchi (32 bit)
